# 🎮 Comment Jouer à FOR2D ROYAL (Sans Admin)

## ✅ Solution sans droits administrateur

Le jeu fonctionne maintenant **directement dans le navigateur** sans besoin de serveur !

## 🚀 Lancement Simple

### Méthode 1 : Double-clic (Le plus simple)
1. **Double-cliquez** sur le fichier `index.html`
2. Le jeu s'ouvre dans votre navigateur par défaut
3. Prêt à jouer !

### Méthode 2 : Via le navigateur
1. Ouvrez **Chrome, Firefox, ou Edge**
2. Faites **glisser-déposer** le fichier `index.html` dans le navigateur
3. Ou allez dans : `Fichier > Ouvrir` et sélectionnez `index.html`

## 🌐 Jouer en Réseau (Peer-to-Peer)

### Comment ça marche ?
- Le jeu utilise **PeerJS** pour créer des connexions directes entre navigateurs
- **Pas besoin de serveur** ni de droits admin
- Fonctionne même sur les PC d'école !

### Créer une partie (Hôte)

1. Ouvrez `index.html` dans votre navigateur
2. Dans le lobby, cliquez sur **"🏠 Créer une partie"**
3. Un **code à 6 caractères** s'affiche (ex: ABC123)
4. **Partagez ce code** avec vos amis :
   - Par SMS
   - Sur Discord/WhatsApp
   - En le disant à voix haute !

### Rejoindre une partie

1. Ouvrez `index.html` dans votre navigateur
2. Cliquez sur **"🔗 Rejoindre"**
3. **Entrez le code à 6 caractères** que l'hôte vous a donné
4. Cliquez sur **"Rejoindre"**
5. Vous apparaissez dans le lobby ! 🎉

## 💡 Conseils

### Pour jouer en classe
- ✅ Chaque joueur ouvre `index.html` sur son PC
- ✅ Un joueur crée la partie et donne le code aux autres
- ✅ Tout le monde peut jouer ensemble !

### Partage du fichier
Si vos amis n'ont pas le jeu :
1. **Copiez le dossier complet** `For2DRoyal` sur une clé USB
2. Donnez-la à vos amis
3. Ils copient le dossier sur leur PC
4. Ils ouvrent `index.html`

### Alternative : Partage réseau
Sur le réseau de l'école :
1. Partagez le dossier sur **OneDrive / Google Drive**
2. Vos amis téléchargent le dossier
3. Ils ouvrent `index.html`

## 🔧 Résolution de problèmes

### Le jeu ne se lance pas
- ✅ Vérifiez que vous avez **tous les fichiers** (pas juste index.html)
- ✅ Le dossier doit contenir : `css/`, `js/`, `index.html`, etc.
- ✅ Essayez un autre navigateur (Chrome, Firefox, Edge)

### La connexion réseau ne fonctionne pas
- ✅ Vérifiez votre **connexion Internet** (PeerJS a besoin d'Internet pour la première connexion)
- ✅ Le code est **sensible à la casse** (ABC123 ≠ abc123)
- ✅ Attendez quelques secondes après avoir créé la partie
- ✅ Si ça ne marche pas, **recréez une nouvelle partie** (nouveau code)

### Le pare-feu bloque
- ✅ Avec PeerJS, **pas de problème de pare-feu** !
- ✅ Les connexions passent par un serveur public autorisé
- ✅ Aucun port local n'est ouvert

## 🎯 Commandes du Jeu

### Dans le Lobby
- **Clic sur PRÊT** - Change ton statut
- **Ctrl + Enter** - Raccourci pour PRÊT/PAS PRÊT
- **Chat** - Appuie sur Entrée pour envoyer un message

### Dans le Jeu (une fois lancé)
- **Q/D ou ←/→** - Déplacement gauche/droite
- **Z ou ↑ ou Espace** - Sauter
- **E ou Clic** - Tirer
